BWH eSign

GET /signing/{recipientId} — the stable link returned by the compatibility API

Confirm your email address

This link identifies an agreement but does not authorize signing on its own. To continue, confirm the address the invitation was sent to; we will email a short code to that address.

Send me a code

After the code: a field for the 6-digit code with a filled “Continue” button above this one, which then reads “Send another code”. A wrong address gets the same page, wording and status as a right one: “If that address matches the one this agreement was sent to, a code is on its way to it.”

Electronic signature service. People sign; the finished PDF is sealed with this service's own certificate.
